# Dance Progression Journal

Native Swift iOS app for client May Nguyen. Phase 1, local data only,
no accounts, no backend. TestFlight delivery 7 Jan 2027.

## Layout

- `DanceProgressionJournal/` — the app target. Swift 6.2, SwiftUI,
  MVVM with Repository and Service layers, SwiftData, iOS 17 minimum,
  iPhone only.
- `DanceProgressionJournalTests/` — unit tests.
- `DanceProgressionJournal.xcodeproj/` — Xcode project, generated by
  `tools/generate_xcodeproj.py`. Re run the generator when files are
  added or removed.
- `DesignSystem/` — the design team's token reference file at repo
  root. The app target carries its own copy under
  `DanceProgressionJournal/DesignSystem/`. See BUILD-NOTES.md for why
  there are two and what to do about it.
- `docs/design/` — design system and screen specs. Single source of
  truth for how the app looks.
- `docs/qa/` — QA plan and verification reports.

## Source of truth

`~/workspace/goals/dance-progression-journal-app/files/dance_progression_journal_roadmap_2026_11_26.md`
